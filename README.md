# Synchronous FIFO (SystemVerilog)

Parameterised synchronous FIFO with a self-checking testbench.

## Features
- Parameters: DATA_WIDTH, DEPTH
- Full / empty flags
- Self-checking testbench, assertions and coverage (planned)

## Folder structure
- rtl/ : design
- tb/ : testbench
- docs/ : waveforms and diagrams

## How to run
Run on EDA Playground (link to be added)
